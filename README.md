# HackerRank Problems

JavaScript solutions for HackerRank algorithm challenges.

## Prerequisites

- [Node.js](https://nodejs.org/) v14+

## Problems

| File | Problem |
|------|---------|
| `apple-orange.js` | Apple and Orange — count fruits landing on a house |
| `birthday-cake-candle.js` | Birthday Cake Candles — find the tallest candle count |
| `birthday-chocolate.js` | Birthday Chocolate — find segments matching birthday criteria |
| `compare-triplets.js` | Compare the Triplets — compare scores element by element |
| `diagonal-difference.js` | Diagonal Difference — absolute difference of matrix diagonals |
| `grading-students.js` | Grading Students — round grades per university rules |
| `mini-max-sum.js` | Mini-Max Sum — find min and max sum of four of five integers |
| `picking-number.js` | Picking Numbers — find the longest subarray with max diff ≤ 1 |
| `time-conversion.js` | Time Conversion — convert 12-hour AM/PM to 24-hour format |

## Running a Solution

```bash
node apple-orange.js
node birthday-cake-candle.js
node compare-triplets.js
# etc.
```

Each file contains the solution function along with sample test cases at the bottom so you can verify the output immediately.
