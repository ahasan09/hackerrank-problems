# HackerRank Problem

Collection of 9 standalone JavaScript files, each solving one HackerRank algorithm problem.

## Tech Stack
- JavaScript (Node.js)

## Project Structure
```
hacker-rank-problem/
└── *.js    # One file per HackerRank problem
```

## Development
```bash
# Run any solution with Node.js
node <problem>.js
```
No package.json or dependencies required.

## Key Notes
- No build step or test runner — solutions are standalone scripts.
